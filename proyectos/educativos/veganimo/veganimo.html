Vegánimo

Diseñadora UI/UX y FrontEnd 2025

Plataforma de dietas veganas personalizadas

Vegánimo es una plataforma enfocada en la creación de dietas veganas personalizadas, donde se combina diseño UI/UX con desarrollo FrontEnd para ofrecer una experiencia fluida y atractiva.

Lenguajes de programación
HTML CSS JavaScript PHP Bootstrap
Competencias técnicas
Maquetación web (HTML, CSS) Interactividad intermedia (JavaScript) Implementación de interfaces desde Figma Animaciones y UI creativas Diseño de avatares Creación de chatbots
Resultados

Mejora en la experiencia de usuario, interfaces atractivas y funcionales, desarrollo de identidad visual (logo y avatares) y la implementación de un chatbot interactivo con animaciones que optimiza la interacción del usuario.
